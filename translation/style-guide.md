# 翻译规范

## 一、硬约束（不可违反）

1. **结构必须与英文源一一对应。** 标题层级、列表项数、表格行列数、代码块数量都不许变。
2. **不许删内容。** 英文有的段落，中文必须有；宁可译得拗口，也不许省略。
3. **不许加内容。** 不补解释、不加译者注、不为通顺而扩写。
4. **URL 一律不改。** 只译链接文字，`(url)` 原样保留。内部链接保持英文原地址——见第七节。
5. **代码不译。** 反引号内、代码块内、URL、文件路径、变量名一律原样。
6. **占位符不碰。** `<unknown .../>`、`<empty-block/>`、`{toggle="true"}` 必须原样保留在原位。
7. **简介 callout 不碰。** 页面顶部的 `<callout>` 是 `Description` 属性的投影。

## 二、人称与语气

- **统一用「你」，禁用「您」。**
- Apple 风格：句子简洁、直接、可执行；少用冗词，避免机械直译；优先主动表达。
- 英文祈使句译成中文祈使句：「Click X to do Y」→「点击 X 执行 Y」，**不要译成「点击 X 以执行 Y」**，也不要变成「你可以点击……」。
- 允许把长句拆成多个中文短句，但**不要拆成多个段落**。
- 面向普通用户，不是给工程师看的。

### 去翻译腔

中文要像原生写的，不要像从英文译过来的。

**「以」作目的连词 —— 一律删掉。** 这是最典型的翻译腔，源于把 `to do` 直译成「以」。

| ❌ 翻译腔 | ✅ 自然中文 |
| --- | --- |
| 点击 `设置` 以打开面板 | 点击 `设置` 打开面板 |
| 使用筛选器以缩小范围 | 用筛选器缩小范围 |
| 选择模板，以快速开始 | 选个模板，就能快速开始 |
| 通过 API 以获取数据 | 通过 API 获取数据 |
| 前往设置页面以进行配置 | 前往设置页面配置 |

`以` 只在这些固定词里保留：**可以、以及、以下、以上、以内、以外、以前、以后、所以、予以、难以、足以、以便、用以、得以**，以及惯用句式 **`以…为准`**（如「以先到者为准」）。除此之外出现的 `以`，基本都是翻译腔。

**其他高频翻译腔**

| ❌ | ✅ |
| --- | --- |
| 进行设置 / 进行配置 / 做出选择 | 设置 / 配置 / 选择 |
| 这允许你导出数据 | 你可以导出数据 |
| 页面被删除时，数据会被清除 | 删除页面后，数据会清除 |
| 如果你想要启用此功能 | 如需启用此功能 / 要启用的话 |
| 需要注意的是 | 注意： |
| 关于这个功能的更多信息 | 这个功能的更多信息 / 了解这个功能 |
| 对于工作空间所有者而言 | 工作空间所有者可以 / 如果你是工作空间所有者 |
| 这会使得页面无法访问 | 之后页面就打不开了 |
| 点击一个按钮 | 点击按钮 |
| 你可以在你的工作空间中创建你的模板 | 你可以在工作空间里创建模板 |

注意区分：**「当…时」本身不是问题**，「当你开始转录时」是正常中文。真正该改的是**被动句堆叠**（「当页面被删除时，数据会被清除」→「删除页面后，数据会清除」）。

**判断标准**：读出来不像中文母语者会说的话，就是翻译腔。宁可短、宁可口语一点，也不要为了"忠实原文"把英文句法原样搬过来。

## 三、引号

- **一律用弯引号** `“ ”`、`‘ ’`——符合 GB/T 15834。
- **禁用折角引号 `「」`**，除非用户明确要求。
- 英文源里的 `"…"` 译成中文时，即使原文是直引号，也要转成弯引号。
- 引号内外不加空格：`他说“好的”。`
- **inline code 和代码块里的引号原样不动**，不做转换。

## 四、空格

| 场景 | 规则 | 示例 |
| --- | --- | --- |
| 中文 ↔ 英文/数字 | 加半角空格 | `使用 Notion 的 3 天` |
| 中文 ↔ 链接 | 链接**前**加半角空格 | `详见 [帮助文档](url)` |
| 链接 ↔ 中文 | 链接 `)` 后紧跟汉字时**加**空格 | `[帮助文档](url) 里写了` |
| 中文标点前后 | **不加**空格 | `Notion，然后` / `支持。同时` |
| 中文标点后紧跟英文 | **不加**空格 | `……。Notion 支持` |
| 链接紧贴标点 | 允许，不加空格 | `详见 [文档](url)。` |
| 数字 + 量词 | 加空格 | `3 天`、`5 个成员` |
| 百分号 / 度数 | 紧贴数字 | `50%`、`90°` |
| 中文括号 | 内外不加空格 | `（Notion）` |
| 破折号 / 省略号 | 前后不加空格 | `——`、`……` |

### 链接两侧的空格（最容易漏的一项）

`[文字](url)` 整体按「英文块」处理：**左边是汉字就必须有半角空格**，右边紧跟汉字也加空格（后面是标点则不加）。

| ❌ | ✅ |
| --- | --- |
| 切换到[新的积分体系](url) | 切换到 [新的积分体系](url) |
| 了解如何[管理你的 AI 积分](url) | 了解如何 [管理你的 AI 积分](url) |
| [新的积分体系](url)从 10 月 19 日起生效 | [新的积分体系](url) 从 10 月 19 日起生效 |
| 详见 [文档](url)。 | 原样，不用改（后面是标点） |

**为什么必漏**：英文原句里链接左边天然带空格（`move to the [new credit system](...)`），照抄 `old_str` 时容易连空格一起搬走；中文句子压短之后，链接左边往往正好落在汉字上，视觉上不刺眼，用户却会当成错误。

译完统一扫正则：`[\u4e00-\u9fff]\[`（汉字紧贴链接）和 `\)[\u4e00-\u9fff]`（链接紧贴汉字），命中即漏。

## 五、标点

- 中文用全角标点：`，。：；？！`
- **标题结尾不加标点**（句号、冒号都不加），与英文源保持一致。
- 列表项结尾不加句号，除该项本身是完整句子。

## 六、UI 元素

- 界面元素名（按钮、菜单、开关、字段）**用反引号包裹**，与英文原文一致：`` 点击 `设置` ``。
- 不要用引号包裹 UI 元素，也不要把 UI 元素译成描述性短语。
- UI 元素名本身要翻译，但反引号保留：`Click "Settings"` → `` 点击 `设置` ``。
- **UI 标签以 Notion 中文界面实际显示为准，不强求与正文术语一致。** 例如 `AI Meeting Notes` 既有写作 `会议记录` 的地方，也有写作 `AI 速记` 的地方——这是 Notion 自身翻译不一致，不是译文错误，**不要去"统一"它**。

## 七、链接策略（重要）

**新译或新写的内部链接，一律保留英文原地址，不做映射。**

```
✅ [账号设置](https://www.notion.com/help/account-settings)
❌ [账号设置](/p/328e8a5565ac81f1b039e85b627e1bbb?pvs=25)
```

原因：中文目标页可能尚未创建、内容未更新，或锚点对应的标题不存在。自动映射会让链接指向不存在的页面，比语言不对更糟。

**用户会在后续维护时自己把英文链接转成 Notion 内部链接。** 所以：

- 我保留英文，但**必须在汇报里把链接全部列出**，他统一改。
- **已有的 `/p/` 内部链接不要碰**，也不要反向改回英文——那是他之前的成果。

需要单独报出的链接类型：

1. **带锚点的内部链接**（`.../help/<slug>#<anchor>`）——锚点指向原文某个标题，用户需手动定位到中文页的对应区块。**这类最需要提醒。**
2. **目标页可能不存在的**（如 `/help/guides/...`）。
3. 链接文字与上下文不符的。

外部链接、非 help 路径的 Notion 链接（`/pricing`、`/security`）原样保留，不用报。

## 八、与英文原文的对应关系

英文源来自 `content/<identifier>.md`，是标准 Markdown，含 frontmatter，且 **CRLF/LF 混排**（切行前需归一化）。

中文现状态来自 `pages.retrieveMarkdown`，是 Notion 自己的 Markdown 方言：

- 子块用 **Tab 缩进**，不是空格
- 标注是 `<callout color="...">` 包裹的块
- 折叠块标题后带 `{toggle="true"}`
- 无法转换的块显示为 `<unknown url="..." alt="..."/>`
- `truncated: true` 表示存在无法转换的块，**不代表内容被截断**

改译文时只动文字，不动这些结构标记。

## 九、输出前自检

逐项确认，缺一项都不交付：

- [ ] 没有出现「您」
- [ ] **没有「XXX 以 XXX」这类翻译腔**（`以` 只应出现在 可以/以及/以下/以上/以内/以前/以后/所以/予以/难以/足以/以便/用以/得以 里）
- [ ] 没有「进行设置」「做出选择」「这允许你」「需要注意的是」这类冗余说法
- [ ] 没有出现 `duplicate → 复制`、`Copy → 复制`
- [ ] 套餐名已中文化（Plus 版 / 商业版 / 企业版 / 免费版）
- [ ] `block` 译成「区块」、`credits` 译成「积分」
- [ ] 引号是弯引号，没有 `「」`
- [ ] 标题没加结尾标点
- [ ] UI 元素用反引号
- [ ] 中英之间、中文标点前后空格符合第四节
- [ ] **链接左侧有空格**：正则 `[\u4e00-\u9fff]\[` 与 `\)[\u4e00-\u9fff]` 均为 0 命中
- [ ] 标题数、列表项数、代码块数与英文源一致
- [ ] 所有 URL 未被改动
- [ ] 已产出「遇到的问题」清单（见汇报格式）
